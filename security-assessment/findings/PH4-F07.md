# PH4-F07 — Container base images are referenced by mutable tags

- Severity: **Medium**
- Status: **Closed — Phase 5 retest passed**
- Asset: `Multi-stage application Dockerfile`
- CWE: CWE-494
- OWASP: OWASP A08:2021 – Software and Data Integrity Failures
- GitHub issue: https://github.com/xuanz3/SecureFlow-Security-Lab/issues/58

## Evidence

Dockerfile FROM instructions are not pinned to registry digests: FROM mcr.microsoft.com/dotnet/sdk:10.0-alpine AS build; FROM mcr.microsoft.com/dotnet/aspnet:10.0-alpine AS final

## Safe reproduction

Inspect every FROM instruction in infrastructure/docker/Dockerfile.

## Technical cause

Version tags can be repointed and do not uniquely identify the bytes used for a build.

## Impact

A future rebuild can consume different base-image content without a source change, weakening reproducibility and provenance.

## Recommendation

Pin each base image by verified digest and update the digest through a reviewed dependency PR.

## Safety boundary

Testing was restricted to project-owned localhost containers and fictional data.

## Phase 5 remediation

Retested successfully in Phase 5. See Issue #58 and `security-assessment/results/phase5/CONTAINER_WORKFLOW_RETEST.md`.
